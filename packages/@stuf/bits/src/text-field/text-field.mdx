# Text Field

`TextField` is the styled single-line input for string values. See [Control Container](?path=/docs/components-control-container--docs) for template and form examples.

## Field states

Use the default appearance for outlined fields and `type: 'search'` for compact search. In settings, place a plain Text Field with `align: 'end'` inside an inline Control Container. The row provides the focus outline. The meal editor can style its plain name field as a centered heading. The join form can style its outlined code field in uppercase and set `maxLength`.

## Add item row

The shopping list uses `appearance: 'plain'` with a leading plus in a 52 px row. The row supplies a full-width divider and shows the trailing Add action when the field contains text beyond whitespace. For a standalone field, provide `ariaLabel` or associate a visible label with its `id`.
