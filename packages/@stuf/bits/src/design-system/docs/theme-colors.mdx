# Theme colors

Choose a token by its role. Theme colors are derived from the palette for the current scheme.

The default follows the operating system. Set `data-theme="light"` or `data-theme="dark"` on the document or a subtree for an override. Use `data-theme="system"` to follow the system again inside an override.
