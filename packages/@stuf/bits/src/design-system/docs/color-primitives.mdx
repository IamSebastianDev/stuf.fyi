# Color primitives

The OKLCH palettes supply the values for theme colors. Lower tone numbers are lighter within each family. Use semantic theme colors in components so the same styles adapt to light and dark mode.

## Neutral

`--stuf-palette-neutral-{tone}` for canvas, surfaces, borders, and text.

<Palette family="neutral" stops={[0, 50, 100, 150, 200, 300, 400, 500, 600, 650, 800, 850, 875, 900, 950]} />

## Mint

`--stuf-palette-mint-{tone}` for accent colors.

<Palette family="mint" stops={[200, 300, 750, 800]} />

## Profile colors

Use the 300 tones of mint, blue, amber, coral, and violet for member profiles. The theme exposes these as `--stuf-color-avatar-*` tokens for avatars and profile color pickers.

## Red

`--stuf-palette-red-{tone}` for errors and destructive actions.

<Palette family="red" stops={[400, 700]} />
