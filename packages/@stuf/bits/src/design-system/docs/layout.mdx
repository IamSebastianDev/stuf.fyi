# Layout

Use spacing to group related controls and keep tap targets easy to distinguish. The values below assume a 16px root size.

- **Spacing.** `--stuf-space-1` through `--stuf-space-7` run from 4 to 28px in steps of `0.25rem`.
- **Control size.** `--stuf-size-control-sm`, `--stuf-size-control-md`, and `--stuf-size-control-lg` provide 44, 48, and 52px minimum sizes.
- **Icon size.** `--stuf-size-icon-sm`, `--stuf-size-icon-md`, and `--stuf-size-icon-lg` provide 16, 22, and 28px glyphs.
- **Corner radius.** `--stuf-radius-sm`, `--stuf-radius-md`, `--stuf-radius-lg`, and `--stuf-radius-xl` provide 8, 12, 16, and 28px corners. Use `--stuf-radius-circle` on square elements for a circle.
