# Layout

Use spacing to group related controls and keep tap targets easy to distinguish. The values below assume a 16px root size.

- **Spacing.** `--stuf-space-1` through `--stuf-space-7` run from 4 to 28px in steps of `0.25rem`.
- **Inline controls.** `--stuf-space-inline-control` gives icons, inputs, and actions 14px of space in rows like Add item.
- **Control size.** `--stuf-size-control-sm`, `--stuf-size-control-md`, and `--stuf-size-control-lg` provide 44, 48, and 52px minimum sizes.
- **Icon size.** `--stuf-size-icon-sm` and `--stuf-size-icon-md` provide 16 and 22px glyphs.
- **Avatar size.** `--stuf-size-avatar-sm` and `--stuf-size-avatar-md` provide 22 and 30px diameters.
- **Status dot.** `--stuf-size-status-dot` provides a 6px diameter beside status text.
- **Progress bar.** `--stuf-size-progress-bar` sets a 4px track height.
- **Corner radius.** `--stuf-radius-sm`, `--stuf-radius-md`, `--stuf-radius-lg`, and `--stuf-radius-xl` provide 8, 12, 16, and 28px corners. Use `--stuf-radius-circle` on square elements for a circle.
- **Raised surfaces.** `--stuf-shadow-raised` adds depth to overlays such as the list switcher.
