# Component inventory

This inventory follows the standalone **Meal Planner Prototype** HTML export and the passkey flow in the app. It covers the planner, meal library, shopping lists, sharing, and settings. The simulated device prompt and demo reset are prototype controls. The browser owns the passkey prompt.

**Implemented** means the primitive is exported by Bits and has a Variants story. **Planned** means the UI is still to be built. Review each Bits addition in its own Variants story before composing the app screens.

## Product terms

- **Lists** are named shared containers such as Home and Cabin weekend. Members, sharing, and list preferences belong here.
- **Shopping** covers the active list’s items, cart, stores, and progress. The navigation label is **List**.
- **Meals** is the active list’s recipe library.
- **Plan** schedules meals for specific days on the active list. Week and day views show the same plan at different levels of detail.
