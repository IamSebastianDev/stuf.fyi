# Interaction

Keep focus, pressed, and disabled states legible in both themes. Let the native element own keyboard activation and disabled behavior.

- Use `--stuf-focus-ring-width` and `--stuf-focus-ring-offset` for visible keyboard focus.
- Use `--stuf-opacity-pressed` and `--stuf-opacity-disabled` for those states.
- Pair `--stuf-duration-fast` with `--stuf-ease-standard` for short transitions. The duration becomes zero when the user prefers reduced motion.
